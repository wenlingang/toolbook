# 对比 staging 和生产的配置

上线前确认两边配置只差该差的地方。

```json name=staging param
{
  "db": { "host": "mysql.staging.svc", "pool": 10 },
  "cache": { "ttl": 60 },
  "features": { "new_checkout": true, "dark_mode": true },
  "log_level": "debug"
}
```

```json name=prod param
{
  "db": { "host": "mysql.prod.svc", "pool": 50 },
  "cache": { "ttl": 300 },
  "features": { "new_checkout": false, "dark_mode": true },
  "log_level": "info"
}
```

```diff name=changes a=$staging b=$prod
```
