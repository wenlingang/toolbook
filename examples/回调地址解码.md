# 拆开一个 OAuth 回调地址

日志里只有一串编码过的回调地址：解码，再把查询参数拆成字段。

```text name=raw param
https%3A%2F%2Fapp.example.com%2Foauth%2Fcallback%3Fcode%3D4%252F0AeaY%26state%3Dxyz%2520123%26scope%3Demail%2520profile
```

```url name=decoded input=$raw
```

```js name=params
const [address, query = ""] = $decoded.split("?");
const fields = query.split("&").filter(Boolean).map(p => p.split("=").map(decodeURIComponent));
({ address, ...Object.fromEntries(fields) })
```
