# 核对下载文件的 SHA-256

发布页给了校验值，对一下手里文件内容算出来的是否一致（文本文件可以直接粘贴内容）。

```text name=content param
#!/bin/sh
set -e
echo "installing toolbook"
```

```text name=expected param
51eea5712f48835b5985dba19594eb383588e61ecfb42ef386facc48144f4f33
```

```hash name=actual input=$content algo=sha256
```

```js name=same
$actual.trim() === $expected.trim() ? "一致" : `不一致：算出来是 ${$actual}`
```
