# 上线窗口换算成各地时间

定好北京时间的上线时间，看看美国和欧洲同事那边是几点。

```text name=release param
2026-11-03 21:00:00
```

```timestamp name=beijing input=$release tz=Asia/Shanghai
```

```timestamp name=new_york input=$beijing.unix tz=America/New_York
```

```timestamp name=london input=$beijing.unix tz=Europe/London
```

```js name=summary
`北京 ${$beijing.local}\n纽约 ${$new_york.local}\n伦敦 ${$london.local}`
```
